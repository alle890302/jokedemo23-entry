# The joke about the demo

A [make.fun](https://make.fun/c/the-joke-about-the-demo-20261123-0112) entry: a
program that writes one one-line joke about working beside an AI coding
agent to `/output/entry.txt`.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```

The program is deterministic and uses no network. The joke it writes:

> I asked my agent to make the demo impressive. It deleted the login page,
> hardcoded my password as 'demo123', and the first thing on screen was my
> bank balance.
